# รูปแบบการอ้างอิง

ตัวอย่างในไฟล์นี้ใช้ชื่อสมมติ (ผู้แต่ง ก, วารสาร ข) เพื่อแสดงรูปแบบเท่านั้น ห้ามนำไปใช้เป็นแหล่งอ้างอิงจริง

## A. โหมด MCU — APA ระบบนาม-ปี (แบบที่วารสารสาย มจร ใช้)

กฎใหญ่: ทุกรายการที่อ้างในเนื้อหาต้องอยู่ท้ายเรื่อง และทุกรายการท้ายเรื่องต้องถูกอ้างในเนื้อหา แหล่งอ้างอิงต้องตีพิมพ์ชัดเจน สืบค้นได้ (หนังสือ วารสาร งานวิจัย)

### A1. ในเนื้อหา

**ต้นเนื้อความ:** ชื่อ-นามสกุลเต็ม (ไม่ใส่ตำแหน่งทางวิชาการ; พระสงฆ์ใช้ชื่อตามที่ปรากฏในงาน) ตามด้วย (ปี)
- สมชาย รักเรียน (2567) กล่าวว่า...
- ...สอดคล้องกับงานวิจัยของสมชาย รักเรียน (2567) ที่พบว่า...
- Somchai Rakrian (2024) explains that... (ในส่วนภาษาอังกฤษ)

**ท้ายเนื้อความ**
| กรณี | รูปแบบ |
|---|---|
| ไทย 1 คน | (สมชาย รักเรียน, 2567) |
| ไทย 2 คน | (สมชาย รักเรียน และสมหญิง ใฝ่รู้, 2567) |
| ไทย ≥ 3 คน | (สมชาย รักเรียน และคณะ, 2567) |
| อังกฤษ 1 คน | (Smith, 2022) — นามสกุลเท่านั้น |
| อังกฤษ 2 คน | (Smith & Brown, 2022) |
| อังกฤษ ≥ 3 คน | (Smith et al., 2022) |
| หลายรายการ | (สมชาย รักเรียน, 2567; Smith, 2022) |
| พระไตรปิฎก | "ข้อความ" (ชื่อคัมภีร์ย่อ (ไทย) เล่ม/ข้อ/หน้า) (มหาจุฬาลงกรณราชวิทยาลัย, 2539) |
| ราชกิจจานุเบกษา/ประกาศ | (ชื่อประกาศ, 2567) หรือ (ราชกิจจานุเบกษา, 2567) |

- เรื่องเดียวกันมีผู้ศึกษาหลายคน ให้เลือกรายการที่ใกล้ปีปัจจุบันที่สุด
- งานภาษาไทยใช้ปี พ.ศ. งานภาษาอังกฤษใช้ปี ค.ศ.
- งานภาษาไทยที่มีชื่ออังกฤษในฐานข้อมูล ให้อ้างตามภาษาต้นฉบับของบทความ (ไทย)

### A2. เอกสารอ้างอิงท้ายเรื่อง

- เรียง **ภาษาไทยก่อน** (ตามลำดับพจนานุกรม) แล้ว **ภาษาอังกฤษ** (A-Z)
- ผู้แต่งซ้ำต่างปี: เรียงปีเก่า → ใหม่ รายการที่ 2 ขึ้นไปพิมพ์ `_____.` แทนชื่อ
- ผู้แต่ง ≥ 3 คน: ชื่อคนแรก + "และคณะ" / "et al."
- บรรทัดที่สองของรายการเยื้องเข้า (hanging indent)
- `/` ในรูปแบบด้านล่าง = เว้นวรรค 1 ครั้ง

| ประเภท | รูปแบบภาษาไทย |
|---|---|
| พระไตรปิฎก (ใส่ทุกครั้งที่อ้างในเนื้อหา) | มหาจุฬาลงกรณราชวิทยาลัย. (2539). พระไตรปิฎกฉบับภาษาไทย ฉบับมหาจุฬาลงกรณราชวิทยาลัย. กรุงเทพฯ: โรงพิมพ์มหาจุฬาลงกรณราชวิทยาลัย. |
| หนังสือ | ผู้แต่ง./(ปี)./ชื่อหนังสือ/(พิมพ์ครั้งที่ x)./สถานที่พิมพ์:/สำนักพิมพ์. |
| บทความในหนังสือ | ผู้แต่ง./(ปี)./ชื่อบทความ./ใน ชื่อบรรณาธิการ,/ชื่อหนังสือ./(น. xx)./สถานที่:/สำนักพิมพ์. |
| ประชุมวิชาการ | ผู้แต่ง./(ปี)./ชื่อบทความ./ใน ชื่อการประชุม./(น. xx-xx)./สถานที่:/ผู้จัดพิมพ์. |
| บทความวารสาร | ผู้แต่ง./(ปี)./ชื่อบทความ./ชื่อวารสาร,/ปีที่(ฉบับที่),/หน้าแรก-หน้าสุดท้าย. |
| สารานุกรม | ผู้แต่ง./(ปี)./ชื่อบทความ./ใน/ชื่อสารานุกรม/(เล่ม x, น. xx-xx). |
| วิทยานิพนธ์/สารนิพนธ์/IS | ผู้แต่ง./(ปี)./ชื่อเรื่อง/(ระดับ ชื่อปริญญา สาขาวิชา)./สถานที่:/มหาวิทยาลัย. |
| รายงานวิจัย | ผู้แต่ง./(ปี)./ชื่อเรื่อง/(รายงานผลการวิจัย)./สถานที่:/หน่วยงาน. |
| สัมภาษณ์ | ชื่อผู้ให้สัมภาษณ์./(ปี, วัน เดือน)./ตำแหน่ง/[บทสัมภาษณ์]. — ไม่เปิดเผยชื่อ: ตำแหน่ง/หน่วยงาน./(ปี, วัน เดือน)/[บทสัมภาษณ์]. |
| เว็บไซต์ | ผู้แต่ง./(ปี)./ชื่อเรื่อง./สืบค้นเมื่อ วัน เดือน ปี จาก URL |
| ราชกิจจานุเบกษา | ชื่อเรื่อง./(พ.ศ., วัน เดือน)./ราชกิจจานุเบกษา./เล่ม x ตอน x./หน้า x. |
| หนังสือพิมพ์ | ผู้แต่ง./(ปี, วัน เดือน)./ชื่อบทความ./ชื่อหนังสือพิมพ์./น. x. |

## B. โหมดทั่วไป

ใช้รูปแบบที่วารสารเป้าหมายกำหนด ถ้าไม่ระบุ ใช้ APA 7th:
- ในเนื้อหา: (Author, Year) / Author (Year) / ≥ 3 คน: (Author et al., Year)
- วารสาร: Author, A. A., & Author, B. B. (Year). Title of article. *Journal Name*, *Vol*(Issue), pages. https://doi.org/...
- หนังสือ: Author, A. A. (Year). *Title of work* (ed.). Publisher.
- งานภาษาไทยในวารสารภาษาอังกฤษ: ใช้ชื่ออังกฤษตามที่บทความระบุ และใส่ [in Thai] ท้ายชื่อเรื่อง
- วารสารไทยหลายแห่งให้แปลรายการอ้างอิงภาษาไทยเป็นภาษาอังกฤษไว้อีกชุด ("Translated Thai References") ให้ตรวจในคำแนะนำวารสาร
- ใส่ DOI เมื่อมี
