# ช่วยเลือกหัวข้อบทความจากเนื้อหาหลักที่ผู้เขียนบอก

ใช้เมื่อผู้ใช้ยังไม่มีชื่อเรื่องชัด มีแค่ "เรื่องที่สนใจ/เนื้อหาที่อยากเขียน" เป้าหมายคือได้หัวข้อ 1 เรื่องที่ (1) ใหม่พอ (2) หาอ้างอิงได้ ≥ 10 (3) ผู้เขียนทำได้จริงด้วยข้อมูลที่มี (4) ตรงขอบเขตวารสาร

## 1. รับวัตถุดิบ

ขอให้ผู้ใช้เล่าอิสระหรือแนบไฟล์ (โครงร่าง วิทยานิพนธ์ ประสบการณ์ทำงาน ข่าว นโยบาย) แล้วถามเสริมเฉพาะที่ขาด ทีละข้อพร้อมคำตอบแนะนำ:
- สาขา/วารสารเป้าหมาย และโหมด (MCU/ทั่วไป)
- ปรากฏการณ์หรือปัญหาที่สนใจ และทำไมสนใจ
- บริบทที่เข้าถึงได้: องค์กร พื้นที่ กลุ่มคน ที่ผู้เขียนทำงานหรือรู้จัก
- ข้อมูลที่มีหรือเก็บได้ (แบบสอบถาม สัมภาษณ์ เอกสาร) → ตัดสินว่าเหมาะกับบทความวิจัยหรือวิชาการ
- ทฤษฎี/หลักธรรมที่ถนัดหรืออยากใช้ (ถ้ามี)
- ข้อจำกัด: เวลา กำหนดส่ง

## 2. แตกองค์ประกอบ

เขียนตาราง:
| องค์ประกอบ | ตัวเลือกที่ได้จากผู้ใช้ | ตัวเลือกที่เสนอเพิ่ม |
|---|---|---|
| ตัวแปร/ปรากฏการณ์หลัก (X) | | |
| บริบท/กลุ่ม/พื้นที่ (Z) | | |
| ทฤษฎี/แนวคิด (T) | | |
| หลักธรรม (D) — โหมด MCU | | (จาก `dhamma-guide.md`) |
| มุมร่วมสมัย (C) | | เทคโนโลยีดิจิทัล/AI, สังคมสูงวัย, ความยั่งยืน/ESG/SDGs, หลังวิกฤต, กฎหมาย/นโยบายใหม่, ความเหลื่อมล้ำ ฯลฯ ที่เกี่ยวกับ X จริง |
| ผลลัพธ์ที่บทความจะให้ (O) | | รูปแบบ/โมเดล, แนวทาง, ปัจจัย, กรอบแนวคิด, ข้อเสนอเชิงนโยบาย |

## 3. สร้างหัวข้อ 5-8 ตัวเลือก

ผสมองค์ประกอบด้วยแบบแผนชื่อเรื่องที่วารสารไทยสายสังคมศาสตร์ใช้บ่อย:

**บทความวิจัย**
- รูปแบบการพัฒนา X ตามหลัก D ของ Z
- ปัจจัยที่ส่งผลต่อ X ของ Z
- แนวทางการส่งเสริม X ตามหลัก D ใน Z
- X ของ Z: การศึกษาเชิงผสานวิธี
- การประเมิน/สภาพและปัญหา X ของ Z

**บทความวิชาการ**
- X ในยุค C: บทวิเคราะห์ตามหลัก D
- แนวคิดใหม่ (ตั้งชื่อ): ข้อความชี้ประเด็น — เช่น "ชื่อแนวคิด: ประเด็นที่บทความเสนอ"
- การบูรณาการ T กับ D เพื่อ O
- X กับ Y: ความท้าทายและทางออก
- กรอบแนวคิด O สำหรับ Z

ให้ตัวเลือกกระจายแนว: อย่างน้อย 1 แบบ "ปลอดภัย" (มีงานรองรับมาก) 1 แบบ "มุมใหม่" (ผสม C หรือบริบทใหม่) และ 1 แบบ "ทำได้เร็ว" (บทความวิชาการจากเอกสาร)

หลักตั้งชื่อ:
- บอกตัวแปรหลักและบริบท อ่านแล้วรู้ว่าบทความตอบอะไร
- ภาษาไทยไม่เกินราว 2 บรรทัด ไม่ขึ้นต้นด้วย "การศึกษา..." โดยไม่จำเป็น
- ชื่ออังกฤษแปลตรงความ ตัวพิมพ์ใหญ่ทั้งหมดตามรูปแบบ มจร
- หลีกเลี่ยงคำโฆษณา (ยั่งยืนอย่างแท้จริง, ปฏิวัติ, ก้าวล้ำ)

## 4. สแกนวรรณกรรมทุกตัวเลือก

```bash
python -I <skill-dir>/scripts/topic_scan.py \
  --topic "<ป้าย>|<คำไทย1>,<คำไทย2>|<english query>" \
  --topic "..." --examples 3 --json <workdir>/topic_scan.json
```
- คำไทยคือคำแกนของ X, D, Z (2-3 คำ) ที่ต้องปรากฏพร้อมกัน ใช้รูปคำที่วารสารใช้จริง (เช่น "พรหมวิหาร" ไม่ใช่ "พรหมวิหารสี่")
- ผลที่ได้: จำนวนงานที่ชื่อเรื่องตรง, ในบทคัดย่อ, แนวโน้ม 3 ปี, จำนวนงานของแต่ละคำ (ประเมินว่าหาอ้างอิงพอไหม), จำนวนงานนานาชาติ (OpenAlex ค้นแบบความเกี่ยวข้อง ตัวเลขใช้เปรียบเทียบระหว่างตัวเลือกเท่านั้น), ตัวอย่างงานล่าสุด
- **อ่านตัวอย่างงานล่าสุดเสมอ** ถ้ามีงานที่ชื่อเรื่องแทบเหมือนตัวเลือก ภายใน 2 ปี ให้ปรับมุม/บริบท หรือตัดตัวเลือกนั้น
- ถ้าผู้ใช้เลือกฐานนานาชาติไว้ ใช้ `academic_search.py` ดูงานต่างประเทศที่ใกล้ที่สุด 3-5 เรื่องของตัวเลือกที่ติดอันดับ

การตีความ (คำนวณให้แล้วในช่อง "ประเมิน"):
| ชื่อเรื่องตรงใน TCI | ความหมาย |
|---|---|
| 0 และบทคัดย่อ ≤ 3 | ช่องว่างสูง — ตรวจก่อนว่าคำค้นไม่ได้แคบหรือสะกดต่างจากที่วารสารใช้ |
| 1-10 | เหมาะสม |
| 11-30 | ค่อนข้างมาก — ต้องมีมุมใหม่ชัด |
| > 30 | อิ่มตัว |
| คำเดี่ยวมีงานน้อย | วรรณกรรมบาง — เสี่ยงหาอ้างอิงไม่ถึง 10 |

## 5. ให้คะแนนและเสนอ

ให้คะแนน 1-5 ต่อเกณฑ์ แล้วแสดงตาราง:

| เกณฑ์ | น้ำหนัก | ดูจาก |
|---|---|---|
| ความใหม่/ช่องว่าง | 25% | ผลสแกน, ความใกล้เคียงกับตัวอย่างงาน |
| ความพอของแหล่งอ้างอิง | 20% | คำเดี่ยว ≥ 10, งานนานาชาติ |
| ความเป็นไปได้ | 25% | ข้อมูลที่ผู้เขียนมี/เก็บได้ เวลา |
| ตรงขอบเขตวารสาร (+ หลักธรรมเชื่อมได้จริงในโหมด MCU) | 15% | เกณฑ์วารสาร |
| ความทันสมัยและคุณค่าต่อผู้อ่าน/นโยบาย | 15% | แนวโน้ม 3 ปี, มุม C |

นำเสนอ 3 อันดับแรก แต่ละหัวข้อมี:
- ชื่อเรื่องไทย / อังกฤษ
- ประเภทที่เหมาะ (วิจัย/วิชาการ) และเหตุผล
- ปัญหาหรือช่องว่างใน 2-3 บรรทัด อ้างตัวเลขจากผลสแกน
- วัตถุประสงค์ร่าง 2-3 ข้อ
- ทฤษฎี + หลักธรรมที่จะใช้
- ข้อมูลที่ต้องมี และความเสี่ยง (เช่น งานใกล้เคียงเพิ่งตีพิมพ์)
- ภาพองค์ความรู้ใหม่ที่น่าจะได้ (1 บรรทัด)

จากนั้นถามด้วย AskUserQuestion ให้เลือก 1 หัวข้อ (มีตัวเลือก "ปรับ/ผสม" ผ่าน Other) หัวข้อที่เลือกพร้อมรายละเอียดข้างต้นบันทึกลง `brief.md` ส่วน "หัวข้อที่เลือก" และเก็บผลสแกน/คะแนนไว้ใน `topic-options.md` แล้วไปขั้นสัมภาษณ์ โดยข้ามคำถามที่ได้คำตอบแล้ว (B5-B9, C10-C11 บางส่วน)

## ข้อห้าม
- ไม่อ้างว่าหัวข้อ "ยังไม่มีใครทำ" ถ้าสแกนแค่ฐานเดียว ให้พูดว่า "ในฐาน TCI พบ n เรื่อง"
- ไม่เสนอหัวข้อที่ต้องใช้ข้อมูลวิจัยที่ผู้เขียนไม่มีทางเก็บได้
- ไม่คัดลอกชื่อเรื่องของงานที่มีอยู่แล้ว
