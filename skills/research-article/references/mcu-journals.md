# เกณฑ์ทั่วไปของวารสารสายพุทธบูรณาการ (แนว มหาวิทยาลัยมหาจุฬาลงกรณราชวิทยาลัย)

สรุปจากแบบแผนที่วารสารในเครือ มจร ใช้ร่วมกัน (ข้อมูลปี 2569) วารสารแต่ละฉบับอาจต่างกันในรายละเอียด **ทุกครั้งให้เปิดหน้า "คำแนะนำสำหรับผู้เขียน" (Author Guidelines) ของวารสารเป้าหมายและไฟล์ต้นแบบล่าสุด แล้วใช้ค่าของวารสารนั้นเมื่อขัดกับไฟล์นี้** (ใน ThaiJO มักอยู่ที่เมนู "คำแนะนำสำหรับผู้เขียน" หรือ "Author Guidelines" ของวารสาร)

## ขอบเขตที่พบบ่อย
พระพุทธศาสนาประยุกต์กับ รัฐศาสตร์ รัฐประศาสนศาสตร์ การจัดการ การศึกษา นิติศาสตร์ บริหารธุรกิจ และสหวิทยาการ ประเภทบทความ: บทความวิจัย บทความวิชาการ (บางฉบับรับบทวิจารณ์หนังสือ)

## เกณฑ์ที่ต้องเช็คกับวารสารเป้าหมาย
| เกณฑ์ | ค่าที่พบบ่อย |
|---|---|
| ความซ้ำ (CopyCat ของ ThaiJO) | รวม ≤ 15% ถึง ≤ 25% แล้วแต่วารสาร, ต่อแหล่ง ≤ 5% |
| ความยาว | 8-15 หน้า A4 (บางฉบับนับไม่รวมเอกสารอ้างอิง หรือจำกัด ≤ 12 หน้า) — ถ้าคำแนะนำกำกวม ใช้ค่าที่เข้มกว่า |
| การพิจารณา | ผู้ทรงคุณวุฒิ ≥ 3 ท่าน แบบ double-blind |
| ค่าธรรมเนียม | เก็บหลังตอบรับ บทความวิจัยมักสูงกว่าบทความวิชาการ ยกเลิกระหว่างพิจารณาอาจต้องจ่ายบางส่วน |
| การส่ง | ไฟล์ .docx ผ่านระบบ ThaiJO; ภาพ ตาราง สมการ ส่งแยกเป็นไฟล์ภาพ (PDF/JPG/GIF/BMP) ด้วย |

## การจัดหน้า
- A4 พิมพ์หน้าเดียว ขอบทุกด้าน 1 นิ้ว ไม่ใส่เลขหน้า
- ฟอนต์ TH Sarabun PSK ทั้งเรื่อง single spacing
- ย่อหน้าเว้น 5 ตัวอักษร (เริ่มพิมพ์ตัวที่ 6)

## ขนาดตัวอักษร
| ส่วน | ขนาด |
|---|---|
| ป้ายประเภท "บทความวิจัย"/"บทความวิชาการ" | 12 pt |
| ชื่อบทความภาษาไทย | 20 pt หนา |
| ชื่อบทความภาษาอังกฤษ | 18 pt หนา ตัวพิมพ์ใหญ่ทั้งหมด |
| ผู้เขียน, หน่วยงาน, E-mail (ไทย/อังกฤษ) | 14 pt |
| หัวข้อหลัก | 18 pt หนา |
| เนื้อหา, คำสำคัญ, ชื่อภาพ/ตาราง, ที่มา | 16 pt |
| เนื้อหาในตาราง | 14 pt |

หัวเรื่อง:
```
ชื่อ-นามสกุลผู้เขียนหลัก1*, ชื่อ-นามสกุลผู้เขียนร่วม2
Name Surname1*, Name Surname2
1หน่วยงาน (ไทย)
1Affiliation (EN)
*Corresponding Author E-mail:
Received……; Revised……; Accepted……
```
พระสงฆ์ใช้ชื่อตามสมณศักดิ์/ฉายา เช่น "พระมหา... ฉายา" หรือ "พระครู... (ชื่อ นามสกุล)"

## โครงสร้างบทความวิชาการ
1. ชื่อเรื่อง (ไทย/อังกฤษ)
2. ผู้เขียน หน่วยงาน อีเมล
3. บทคัดย่อ 300-400 คำ 1 ย่อหน้า + คำสำคัญ 3-5 คำ
4. Abstract (แปลตรงตามบทคัดย่อไทย) + Keywords
5. **บทนำ** — ทบทวนแนวคิดและทฤษฎีที่เป็นฐานคิดในการวิพากษ์
6. **เนื้อหา** — ตั้งหัวข้อตามประเด็นจริง (ไม่ใช้คำว่า "เนื้อหา" เป็นหัวข้อ)
7. **องค์ความรู้ใหม่** — โมเดล/แผนภาพ + คำอธิบาย
8. **สรุป** — สั้น กะทัดรัด
9. **เอกสารอ้างอิง**

## โครงสร้างบทความวิจัย
1-4 เหมือนข้างบน แต่บทคัดย่อ 300-400 คำ **2 ย่อหน้า**: "บทความวิจัยนี้มีวัตถุประสงค์เพื่อ 1)... 2)... และ 3)... [วิธีวิจัยโดยย่อ]" / "ผลการวิจัยพบว่า 1)... 2)... และ 3)..."
5. **บทนำ** (ไม่เกิน 6 ย่อหน้า): ความเป็นมา (มีอ้างอิง) → ปัญหาที่นำสู่การวิจัย เชื่อมพื้นที่วิจัย + งานที่ผ่านมา → ทฤษฎีที่ใช้ → สรุปเชื่อมสู่คำถามและวัตถุประสงค์
6. **วัตถุประสงค์การวิจัย** (ข้อเดียวไม่ใส่เลข)
7. **วิธีดำเนินการวิจัย** 5 หัวข้อ: 1) รูปแบบการวิจัย 2) ประชากร กลุ่มตัวอย่าง/ผู้ให้ข้อมูลสำคัญ/แหล่งข้อมูล 3) เครื่องมือ 4) การเก็บรวบรวมข้อมูล 5) การวิเคราะห์ข้อมูล
8. **ผลการวิจัย** ครบตามวัตถุประสงค์ทีละข้อ
9. **อภิปรายผลการวิจัย** ทีละข้อ: พบอะไร สะท้อนอะไร สอดคล้อง/ไม่สอดคล้องกับงานใด (มีอ้างอิง)
10. **องค์ความรู้ใหม่** โมเดล/แผนภาพ + คำอธิบาย
11. **สรุปและข้อเสนอแนะ** สรุปสั้น + ข้อเสนอแนะการนำไปใช้ + การวิจัยครั้งต่อไป
12. **กิตติกรรมประกาศ** (เฉพาะได้รับทุน หรือชื่อบทความต่างจากวิทยานิพนธ์ต้นทาง) ระบุแหล่งทุนและเลขสัญญา
13. **เอกสารอ้างอิง**

## ภาพและตาราง
```
[ภาพ]
ภาพที่ 1 ชื่อภาพ          (16 pt ใต้ภาพ)
ที่มา: (ถ้ามี)
คำอธิบายภาพ

ตารางที่ 1 ชื่อตาราง       (16 pt เหนือตาราง)
[ตาราง 14 pt]
คำอธิบายตาราง
```
ตารางข้ามหน้า: หน้าถัดไปพิมพ์ "ตารางที่ 1 ชื่อตาราง (ต่อ)"

## กระบวนการพิจารณาโดยทั่วไป และนัยต่อการเขียน
1. ผู้เขียนส่งผ่าน ThaiJO
2. ผู้ช่วยบรรณาธิการตรวจ **รูปแบบ** และ **ความซ้ำ** → ปฏิเสธทันทีถ้ารูปแบบไม่ถูกหรือซ้ำเกินเกณฑ์
3. บรรณาธิการตรวจ **ขอบเขตและวัตถุประสงค์วารสาร** → ปฏิเสธถ้าไม่ตรง
4. บรรณาธิการประจำบทส่งผู้ทรงคุณวุฒิ ≥ 3 ท่าน (ราว 2 สัปดาห์)
5. ผลตัดสิน: ยอมรับ / แก้ไขเล็กน้อย (แก้ราว 2 สัปดาห์) / แก้ไขมาก (2-4 สัปดาห์ แล้วกลับไปผู้ทรงฯ) / ปฏิเสธ
6. บรรณาธิการตัดสินรอบสุดท้าย → ตรวจความถูกต้องและจัดอาร์ตเวิร์ค

นัย: สองด่านแรกตกเพราะเรื่องที่แก้ได้ก่อนส่ง (รูปแบบ อ้างอิงผิด ความซ้ำ ขอบเขต) วารสารสายนี้ระบุว่าบทความที่อ้างอิงไม่ถูกต้องจะไม่ถูกส่งผู้ทรงคุณวุฒิจนกว่าจะแก้ จึงต้องผ่านขั้นตรวจก่อนส่งให้ครบ

## แบบแผนของบทความที่ผ่านการตีพิมพ์ (บทความวิชาการ)
- **บทคัดย่อ:** วัตถุประสงค์ → แนวคิด/ข้อเสนอที่ผู้เขียนตั้งชื่อเอง → กรอบที่ใช้วิเคราะห์ → มิติการวิเคราะห์ → ผล → โมเดลที่สังเคราะห์ → ทางออกตามหลักธรรม → ประโยคปิดเชิงนัยสำคัญ
- **บทนำ 2-4 ย่อหน้า:** เปิดด้วยเหตุการณ์/ข้อมูลจริงที่ระบุได้ชัด (มีอ้างอิง) → ชี้ว่ากรอบเดิมอธิบายไม่พอ (อ้างงานเดิม) → "ผู้เขียนเห็นว่า..." + ข้อเสนอ + โครงของบทความ + เหตุผลที่ใช้หลักธรรม
- **เนื้อหา 3-5 หัวข้อ:** ตั้งชื่อหัวข้อเป็น "ชื่อมิติ: ข้อความชี้ประเด็น" แต่ละหัวข้อปิดด้วยย่อหน้า "สรุปได้ว่า..."
- **ส่วนหลักธรรม:** 2-3 หลัก ไล่เป็นระบบ แต่ละหลัก: ความหมาย (อ้างตำรา/พระไตรปิฎก) → ขยายสู่บริบท → อ้างงานที่ใช้หลักใกล้เคียง → ผูกกับกรณี
- **องค์ความรู้ใหม่:** ภาพโมเดล + คำอธิบายไล่ทุกองค์ประกอบ อาจมีภาพที่สองเชื่อมหลักธรรมเข้ากับโมเดล
- **สรุป 1-2 ย่อหน้า:** ไม่มีข้อมูลใหม่
- **เอกสารอ้างอิง:** ราว 15-25 รายการ ส่วนใหญ่เป็นบทความวารสาร 1-3 ปีล่าสุด ผสมไทย-อังกฤษ และตำราหลักธรรม

ลีลาที่ควรเลียน:
- ผู้เขียนมีจุดยืน ("ผู้เขียนเห็นว่า", "ในมุมมองของผู้เขียน") วางหลังหลักฐาน แยกข้อมูลกับการตีความให้เห็น
- ทุกย่อหน้าเนื้อหามีอ้างอิงอย่างน้อย 1 รายการ ใช้ทั้งแบบต้นเนื้อความและท้ายเนื้อความ
- ใช้ตัวเลขจากงานที่อ้างแทนคำคุณศัพท์
- ศัพท์อังกฤษใส่วงเล็บครั้งแรกครั้งเดียว: แบบจำลองระดับแนวหน้า (Frontier Model)

ข้อผิดพลาดที่พบได้แม้ในบทความที่ตีพิมพ์แล้ว (ต้องตรวจเสมอ):
- Abstract ภาษาอังกฤษไม่ตรงกับบทคัดย่อภาษาไทย (เช่น คัดลอก Abstract ของบทความอื่นมาโดยไม่ตั้งใจ)
- เว้นวรรคในวงเล็บปี "( 2569)"
