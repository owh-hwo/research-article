# โหมดทั่วไป: วารสารหรือแหล่งเผยแพร่อื่น

## 1. เก็บเกณฑ์ของวารสารเป้าหมาย

1. ขอชื่อวารสาร/ลิงก์จากผู้ใช้ ถ้าไม่มี ช่วยเลือก: WebSearch "<สาขา> วารสาร TCI กลุ่ม 1" หรือดูวารสารที่ตีพิมพ์งานใกล้เคียงจากผล `tci_search.py` ให้ตัวเลือก 2-3 วารสารพร้อมขอบเขต ค่าธรรมเนียม ระยะเวลาพิจารณา
2. WebFetch หน้า Author Guidelines / คำแนะนำสำหรับผู้เขียน (ThaiJO มักอยู่ที่ `/index.php/<journal>/about/submissions` หรือ `/authorsguidelines`) และดาวน์โหลดไฟล์ต้นแบบ (template) ถ้ามี แล้วแปลงข้อความด้วย pypdf/python-docx (ถ้าลิงก์เป็นไฟล์ฝากออนไลน์ ให้ผู้ใช้ดาวน์โหลดมาเองหรือให้ path)
3. สรุปเป็นตารางใน `brief.md`:

| เกณฑ์ | ค่า |
|---|---|
| ประเภทบทความที่รับ | |
| ความยาว | |
| ฟอนต์/ขนาด/ระยะ | |
| โครงสร้างหัวข้อ (ตามลำดับ) | |
| บทคัดย่อ (คำ), คำสำคัญ | |
| รูปแบบอ้างอิง (APA6/APA7/Vancouver/วารสารกำหนดเอง), ต้องแปลอ้างอิงไทยเป็นอังกฤษหรือไม่ | |
| เกณฑ์ความซ้ำ | |
| ภาพ/ตาราง | |
| ค่าธรรมเนียม, ระบบส่ง | |

ถ้าคำแนะนำไม่ระบุข้อใด ใช้ค่าเริ่มต้น: A4, TH Sarabun PSK 16, บทคัดย่อ 250-300 คำ, คำสำคัญ 3-5, APA 7

## 2. โครงสร้างเริ่มต้น (ถ้าวารสารไม่กำหนด)

- **บทความวิจัย (IMRaD):** บทคัดย่อ/Abstract → บทนำ (รวมวัตถุประสงค์) → ทบทวนวรรณกรรมและกรอบแนวคิด → วิธีดำเนินการวิจัย → ผลการวิจัย → อภิปรายผล → สรุปและข้อเสนอแนะ → เอกสารอ้างอิง
- **บทความวิชาการ:** บทคัดย่อ/Abstract → บทนำ → เนื้อหา (หัวข้อตามประเด็น) → บทสรุป (และข้อเสนอแนะ) → เอกสารอ้างอิง
- ส่วน "องค์ความรู้ใหม่" เป็นเอกลักษณ์ของวารสาร มจร และวารสารสายสังคมศาสตร์บางแห่ง โหมดทั่วไปใส่เมื่อวารสารกำหนด แต่แผนภาพกรอบแนวคิด/โมเดลยังแนะนำให้มีเสมอ

## 3. สิ่งที่ยังบังคับเหมือนโหมด MCU

- อ้างอิงจริง ≥ 10 รายการ ตรวจได้ บันทึกใน refs.json
- ไม่สร้างข้อมูลวิจัย
- ผ่านสกิล thai-humanizer (เนื้อหาไทยและ Abstract อังกฤษ)
- check_citations.py ผ่าน (ใช้ `--style apa7` ถ้าเป็นวารสาร APA 7)

## 4. หลักธรรมในโหมดทั่วไป

ไม่บังคับ ถ้าผู้ใช้ต้องการ ใช้ `dhamma-guide.md` เหมือนเดิม แต่การอ้างพระไตรปิฎกให้ปรับตามรูปแบบของวารสาร (APA 7 ปกติอ้างคัมภีร์ศาสนาในเนื้อหาเท่านั้น หรือใส่รายการ Tipitaka ตามที่วารสารกำหนด)

## 5. การสร้าง .docx

`build_docx.py` มีตัวเลือก `--profile general` (ไม่มีป้ายประเภทบทความ, ไม่มีบรรทัด Received/Revised/Accepted) และ `--body-size`, `--title-size`, `--heading-size`, `--font` เพื่อให้ตรงเกณฑ์วารสาร ถ้าวารสารมี template .docx ของตนเอง ให้ใช้สกิล `docx` เทเนื้อหาลง template นั้นแทน
