# การบูรณาการหลักพุทธธรรมเข้ากับบทความ

ใช้ในโหมด MCU (บังคับ) และโหมดทั่วไปเมื่อผู้เขียนต้องการ

## 1. เลือกหลักธรรม

1. ระบุแนวคิด/ตัวแปรหลักของบทความ แล้วดูตารางจับคู่ด้านล่างเพื่อหาหลักธรรมที่นิยมใช้คู่กัน
2. เปิด `dhamma-principles.md` ดูองค์ธรรม แล้วถามว่า **องค์ธรรมแต่ละข้ออธิบายกลไกของปัญหาได้จริงหรือไม่** เลือก 1-3 หลักที่ตอบได้ ไม่เลือกเพราะนิยม
3. ค้น TCI ว่ามีงานที่ใช้หลักนั้นกับเรื่องใกล้เคียงหรือไม่ (`tci_search.py "<หลักธรรม>" "<ตัวแปร>"`) ถ้ามี ใช้เป็นหลักฐานว่าการบูรณาการนี้มีที่มา ถ้าหัวข้อใหม่ (เช่น AI, ESG) ยังไม่มีงาน ให้ตีความจากความหมายเดิมของหลักธรรมอย่างระมัดระวังและบอกชัดว่าเป็นการตีความของผู้เขียน
4. ถ้าผู้ใช้มีคู่มือหลักธรรมของหลักสูตร/สถาบันของตนเอง (PDF) ให้ขอ path แล้วแปลงเป็นข้อความด้วย pypdf ลงในโฟลเดอร์งานของบทความ เพื่อใช้ค้น ตารางในคู่มือเหล่านั้นมักมี "แนวคิด → ตัวชี้วัด/องค์ประกอบ → แหล่งที่มา" ซึ่งเป็นเบาะแสหางานต้นฉบับได้ดี แต่ต้องตรวจเลขพระไตรปิฎกซ้ำเสมอ

## 2. ตารางจับคู่ที่พบบ่อยในงานวิจัยเชิงพุทธบูรณาการ

เป็นแนวทางเริ่มต้นจากแบบแผนที่พบในงานวิจัยสายรัฐศาสตร์ รัฐประศาสนศาสตร์ และการจัดการเชิงพุทธ ไม่ใช่ข้อบังคับ

| แนวคิด/ตัวแปร | หลักธรรมที่นิยมใช้ |
|---|---|
| ภาวะผู้นำ, คุณลักษณะผู้นำ | พรหมวิหาร 4, ปาปณิกธรรม 3, สัปปุริสธรรม 7, อธิปไตย 3 |
| ผู้นำทางการเมือง, ธรรมาภิบาลของผู้ปกครอง | ทศพิธราชธรรม 10, ราชสังคหวัตถุ 4, จักรวรรดิวัตร |
| การบริหารจัดการ, ประสิทธิผล, ประสิทธิภาพ, สมรรถนะ | อิทธิบาท 4, พละ 4, พละ 5 |
| การบริการสาธารณะ, คุณภาพบริการ, ความพึงพอใจ | สังคหวัตถุ 4 (+ อัตถะ 3, คิหิสุข 4) |
| การมีส่วนร่วม, การมีส่วนร่วมทางการเมือง | อปริหานิยธรรม 7 |
| ความขัดแย้ง, ความปรองดอง, การกระจายอำนาจ | สาราณียธรรม 6 |
| ธรรมาภิบาล, จริยธรรม | ธรรมเป็นโลกบาล 2, สุจริต 3, ฆราวาสธรรม 4 |
| การพัฒนาทรัพยากรมนุษย์, คุณภาพชีวิต, ผู้สูงอายุ | ไตรสิกขา, ภาวนา 4 |
| การพัฒนาองค์การ, ปัจจัยการบริหาร | จักร 4, สัปปายะ 4, วุฑฒิธรรม 4 |
| ท่องเที่ยว, สิ่งแวดล้อม, เมืองอัจฉริยะ | สัปปายะ 4, สัปปายะ 7 |
| ความผูกพันต่อองค์กร, การธำรงรักษาบุคลากร | คหบดีธรรม 4, ฆราวาสธรรม 4, สังคหวัตถุ 4 |
| แรงจูงใจในการทำงาน | ทิฏฐธัมมิกัตถประโยชน์ 4, สังคหวัตถุ 4 |
| การบริหารความเสี่ยง, การจัดการขยะ | ปธาน 4, วุฑฒิธรรม 4, อิทธิบาท 4 |
| การเงิน งบประมาณ | คิหิสุข 4, ทิฏฐธัมมิกัตถประโยชน์ 4 |
| การสื่อสาร, การสื่อสารทางการเมือง | วจีสุจริต 4, เทศนาวิธี 4, วาจาสุภาษิต 5 |
| เทคโนโลยีดิจิทัล, การรู้เท่าทันข้อมูล | ปัญญา 3, กาลามสูตร 10, โยนิโสมนสิการ |
| ความเสมอภาค, การตัดสินใจที่เป็นธรรม | อคติ 4 |
| ความไว้วางใจ, การเรียนรู้ของพลเมือง | อารยวัฑฒิ 5, องค์คุณพหูสูต 5 |
| พฤติกรรมพลเมือง, วินัย | นาถกรณธรรม 10, ศีล 5 |
| ความรับผิดชอบต่อผลกระทบ (AI, นโยบาย) | กัมมัสสกตา, อัปปมาทะ |
| การแบ่งปันทรัพยากรอย่างเป็นธรรม | สาธารณโภคิตา (สาราณียธรรม 6), สังคหวัตถุ 4 |
| นายจ้าง-ลูกจ้าง, แรงงานสัมพันธ์ | ทิศ 6 (เหฏฐิมทิศ) |

## 3. ยืนยันเลขอ้างอิงพระไตรปิฎก

รูปแบบในเนื้อหา: `(ชื่อคัมภีร์ย่อ (ไทย) เล่ม/ข้อ/หน้า) (มหาจุฬาลงกรณราชวิทยาลัย, 2539)` เช่น `(องฺ.จตุกฺก. (ไทย) 21/32/...)`
ตัวย่อคัมภีร์ดูใน `citation-style.md`

ขั้นตอน:
1. ค้นชื่อหมวดธรรม (ภาษาไทยหรือบาลี) ในพระไตรปิฎกออนไลน์ เช่น `https://84000.org/` (มีระบบค้นพระไตรปิฎกฉบับภาษาไทย) หรือบริการพระไตรปิฎกออนไลน์ของ มจร ด้วย WebSearch/WebFetch
2. ระบุนิกาย/คัมภีร์ เล่ม และข้อ ให้ตรงกับฉบับ มจร (การแบ่งเล่มของพระไตรปิฎกฉบับภาษาไทย 45 เล่มใกล้เคียงกัน แต่เลขข้อและเลขหน้าต่างกันได้ระหว่างฉบับ ถ้าแหล่งที่ค้นไม่ใช่ฉบับ มจร หรือได้เลขไม่ครบ ให้บอกผู้ใช้ตรวจกับเล่มจริง)
3. ตรวจความสอดคล้อง: เลขเล่มต้องอยู่ในช่วงของคัมภีร์นั้น (เช่น ทีฆนิกาย 9-11, มัชฌิมนิกาย 12-14, สังยุตตนิกาย 15-19, อังคุตตรนิกาย 20-24, ขุททกนิกาย 25-33, อภิธรรม 34-45, วินัย 1-8) ถ้าไม่สอดคล้อง แปลว่าผิด
4. ถ้ายืนยันไม่ได้ อย่าใส่เลข ให้อ้างความหมายจากพจนานุกรมพุทธศาสตร์ ฉบับประมวลธรรม ของ พระพรหมคุณาภรณ์ (ป.อ. ปยุตฺโต) แทน และบันทึกใน `refs-log.md`
5. คำพูดตรงจากพระไตรปิฎกให้สั้น ไม่เกิน 2-3 บรรทัด อยู่ในเครื่องหมายคำพูด

## 4. เขียนบูรณาการให้ผู้ทรงคุณวุฒิยอมรับ

- อธิบายองค์ธรรมแต่ละข้อด้วยภาษาของบริบทเรื่อง (เช่น อิทธิบาท 4 ในการบริหารโครงการ: ฉันทะ = ความผูกพันต่อเป้าหมายของทีม ...) ไม่ใช่แค่แจกแจงชื่อ
- ขยายความหมายดั้งเดิมสู่บริบทใหม่อย่างมีเหตุผล: ความหมายเดิม → หลักการที่ถอดได้ → การประยุกต์กับกรณี
- จับคู่องค์ประกอบทฤษฎีตะวันตก ↔ องค์ธรรม เป็นตาราง/แผนภาพ เหมาะกับส่วนองค์ความรู้ใหม่
- อ้างงานวิจัยที่ใช้หลักธรรมเดียวกันอย่างน้อย 1-2 ชิ้น
- ถ้าองค์ธรรมใดไม่เกี่ยวกับปัญหา อย่าฝืนใส่
- วางส่วนหลักธรรมเป็น "ทางออก/ข้อเสนอ" หรือ "กรอบวิเคราะห์" ที่เชื่อมกับเนื้อหาก่อนหน้า ไม่ใช่ย่อหน้าแปะท้าย
